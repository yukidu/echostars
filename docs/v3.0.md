# v3.0（2026-10-02）

## 本次修改
- 彙整 v2.9、v3.0 與既有改版紀錄。
- 浮動播放器可拖曳；移除長條播放器與三態控制。置頂箭頭移到浮動播放器左側；點擊音檔資訊開啟詳細頁時間軸。
- 初次 Google 註冊停留會員頁；會員、上傳、管理與頭像儲存操作移至標題列。
- 會員四個分頁縮短文字，保留左右箭頭；天賦數、命數與安麗編號顯示調整。
- 統一彈窗頂端位置與配色下拉選單；首頁篩選置中、防止裁切。
- 九宮格亮綠天賦圈、單次命數顯示；統計採 1/4/7、2/5/8、3/6/9。
- 正式站補上關鍵字增刪改、獎銜審核；失敗不再靜默。
- 留言修改限定作者，移除管理員／姓名比對捷徑；留言呈現姓名及獎銜。
- 移除原始示範資料、未使用預設關鍵字及虛構學習進度；精確比對舊資料後清理，保留有修改的真實資料。
- 學習卡使用最新評價與留言，生命靈數由生日計算；匯出留言不再誤標獎銜審核員。
- 搜尋空白時不顯示建議；可搜尋講者、獎銜、系列、日期、教材名稱及其餘上傳資訊。
- 首頁音檔間距縮減、顯示評價人數，關鍵字區精簡，留言預覽先呈現已載入資料再更新。
- 分享／匯出按鈕同色置中放大；網址只分享一次；/share/:id 提供封面 Open Graph 資訊。
- 詳細頁資訊區與播放器交換，日期靠右，系列可換行。
- 安裝入口僅留漢堡選單；支援的瀏覽器直接開啟原生安裝確認，不另彈文字視窗。
- 新手首頁提示與較高導覽列。
- Cache Storage 儲存實際音檔；聽完超過 95% 刪除；15 天未聽於下次啟動清理。離線時使用已完整保存的音檔。

## 檢查與平台限制
- TypeScript 與 Vite 正式版建置。
- 14 項回歸檢查，包含關鍵字、審核、留言作者限制及既有資料保存。
- 424 × 933 CSS 像素手機視窗檢查（約對應 1272 × 2800 裝置像素、3 倍密度）。
- LINE 封面由分享頁 OG metadata 提供；LINE 自身快取更新時間由其服務決定。
- Safari 沒有 beforeinstallprompt API；需由瀏覽器分享選單加入主畫面，網站不能代替作業系統完成安裝。
- 跨域來源音檔須允許 CORS，且裝置有足夠儲存空間，才能完整離線保存。
- 本次未重新設計全站帳戶驗證系統；API 身份仍沿用既有 Email／裝置識別協定。
